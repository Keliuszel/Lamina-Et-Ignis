Lamina et Ignis
Lamina et Ignis is a Minecraft Mod which aims to bring quality-made content inspired by the 150-50 BC,
It is primarily designed & dedicated for the server with identical name, but can also be used for personal use.


Mod Features & Additions

New underground ores (such as copper or tin)
Ores (Iron, Copper, Tin) now drop their Raw counterparts
 - Raw ore needs to be smelted in order to obtain their ingot counterparts
 - Smelting process takes up a lot more time and is based on the ore tier.
 - There are also Crude variants to be obtained within the process
New tools such as Hammers
Garum (Roman speciality, a rotten fish sauce)
Coin Minting process for "Chalkoui" (Ancient Greeks lowest coin)

Planned Mod Features
Adding Tool Handles
Adding Flax plant, crude fabric and fabric.
Flour and Dought
Woodworking and Woodprocessing
Leatherworking and Leatherprocessing
